# ctmc-pbee

Performance-Based Earthquake Engineering (PBEE) is generalized by describing the damage state of a
structure with a continuous-time Markov chain (CTMC): damage, recovery, and repeated earthquakes over time.
A single model gives both **reliability** (β) and **resilience** (ρ).

## Installation

```bash
conda env create -f environment.yml
conda activate ctmc-pbee
python -m ipykernel install --user --name ctmc-pbee --display-name "Python (ctmc-pbee)"
```

Alternatively, with pip only (Python 3.13): `pip install -r requirements.txt` and then `pip install -e .`

## Getting started

Open `examples/01_quickstart.ipynb` with the kernel *Python (ctmc-pbee)*. It is a short guided tour:
build the CTMC of a structure, then compute reliability and resilience, and see the effect of the repair time.

## Repository structure

```
notebooks/   reproduction of the paper figures
               01_toy_example.ipynb   Section 3 (Figs. 3–7)
               02_case_study.ipynb    Section 4 (Figs. 9–13, Tables 4–5)

examples/    quick guide (01_quickstart.ipynb)

data/        input data
output/      figures regenerated by the notebooks
```

A short user manual, with detailed help on the functions, will follow.

## Data

`data/hazard-curves-ESHM20-20250819.pkl` contains seismic hazard curves taken from the
2020 European Seismic Hazard Model (ESHM20), distributed by EFEHR under the
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) license. The curves were extracted for
the case-study site and saved as a Python pickle.

> L. Danciu, S. Nandan, C. Reyes, R. Basili, G. Weatherill, C. Beauval, A. Rovida, S. Vilanova,
> K. Sesetyan, P.-Y. Bard, F. Cotton, S. Wiemer, D. Giardini (2021).
> *The 2020 update of the European Seismic Hazard Model: Model Overview.*
> EFEHR Technical Report 001, v1.0.0. https://doi.org/10.12686/a15

> L. Danciu et al. (2024). *The 2020 European Seismic Hazard Model: overview and results.*
> Natural Hazards and Earth System Sciences, 24, 3049–3073. https://doi.org/10.5194/nhess-24-3049-2024

ESHM20 output datasets: https://doi.org/10.12686/ESHM20-OUTPUT

`data/recovery.json` contains the recovery times used in the paper.
